Everyday tools, within reach

Find help and privacy information for Orbit Command Center, a free Windows desktop workspace published by Leon23. Arrange notes, tasks, timers, calculations and other everyday tools in a movable HUD or use the full workspace.

The initial Microsoft Store edition works offline for its core tools. It includes no AI chat, voice conversation, wake-word listener or API-key setup. Opening a shortcut to an external website or application uses that external service and its own settings.

Support

Get help with panels, saved work, displays, Game Mode and optional startup. Contact orbitcommandcenter.leon23@outlook.com with a brief description and version information. Do not send credentials or private workspace files. No diagnostics or notes are attached automatically.

Privacy

Read how the offline edition stores local records and how optional clipboard/folder tools work. Ordinary database files and exports are not encrypted by Orbit; protect your Windows account and independent backups.

Release status

The Store release is being prepared. This site provides support and privacy information only, with no installer, payment or subscription. The personal AI build is separate from the initial Store edition.
