Orbitavelle / Offline Store edition

Help with your workspace.

Publisher: Leon23 · Last updated October 29, 2026 · Store release preparation

Get help

Orbitavelle is a free Windows desktop workspace for notes, tasks, timers and everyday tools. The initial Store edition has no AI chat, voice conversation, wake-word listener or API-key setup. The separate personal AI version is not the Store package described here.

For bugs, accessibility feedback or privacy questions, email orbitcommandcenter.leon23@outlook.com. Include the Orbitavelle version, Windows version, what you tried, what you expected and the error wording. Support is provided by the independent publisher, Leon23; a fixed response time is not guaranteed.

Do not send passwords, API keys, databases, recordings or private notes. Redact names, paths and other personal details from screenshots. Orbitavelle does not attach diagnostics or workspace contents to email automatically.

Arrange the HUD

Click a group circle to expand or collapse its panels. Drag the circle itself to move the group. Drag a panel by its move area to reposition it independently; panels may overlap. Individual collapse controls reduce the space a panel occupies. Tidy rearranges your layout, so use it only when you want that change.

Use more than one screen

In Settings, use Move Orbitavelle to a screen and Move to screen to transfer the current window. Interface size on this screen adjusts readability. These controls do not require you to change Windows display settings. If reporting a display problem, include each screen's Windows scaling and explain which controls are affected.

Keep Orbitavelle out of games

Game Mode uses the executable rules you configure; it is not a promise to recognize every game automatically. In Settings → Game executables, add the game's process name or absolute executable path. Exact paths are more precise; inaccessible paths remain unmatched. Use Game Mode override → Automatic for rule-based detection and review the restore-after-game preference. An ordinary fullscreen application may keep Orbitavelle visible. Universal fullscreen-video hiding is not promised.

If hiding fails, report the rule type, process name and observed behavior without sharing private paths. Do not disable Windows security protections to make a game rule work.

Login startup and quitting

Login startup is optional. Change Launch at login in Settings and save your preferences. Windows may require its own approval or prevent changes. Closing a window can hide Orbitavelle; use Quit Orbitavelle from its tray menu or Settings → Workspace & data to exit fully. The tray icon may be under the Windows taskbar's hidden-icons arrow.

Clipboard and watched folders

Clipboard history is optional and starts off. It stores copied text locally and is not secure password storage. Review exclusion and history controls before enabling it. Folder watching records local activity only for folders you configure. Turning a feature off does not erase earlier records or independent backups.

Saved work and backups

Notes, tasks, layouts and preferences are stored locally. In Settings → Workspace & data, Create database backup makes a consistent database copy inside this installation's storage. Keep a separate copy in a location you control before relying on it for uninstall/recovery; a backup left inside package storage is not independent of that installation. Treat databases and exports as sensitive because Orbitavelle does not encrypt ordinary records itself.

Uninstall can remove package storage and backups kept inside it. Keep an independent copy outside Orbitavelle before uninstalling. Quit Orbitavelle before restoring and do not overwrite an existing workspace or a running database. Contact support for recovery steps appropriate to your installed version.

Privacy

The privacy notice explains local records, optional clipboard and folder tools, support correspondence, and this website. This support site has no app download or purchase flow.
