Orbitavelle / Offline Store edition

Your data, explained.

Publisher: Leon23 · Last updated October 29, 2026 · Store release preparation

This notice covers the offline Microsoft Store edition. Separate personal AI builds are not part of this Store release and are not covered by this edition-specific notice.

Orbitavelle stores notes, tasks, projects/courses, preferences, layouts and tool data on this computer in the installation's Windows application storage. Optional folder watches record local activity summaries. System panels read local performance information; game/fullscreen handling may inspect the active application.

Optional clipboard history is off by default. Its default limit is 50 unpinned entries, adjustable from 20 to 200; pinned entries are outside that count. This is an entry count, not an automatic age-based expiry. Source-application exclusions and clear-history controls are available. Exclusions cannot guarantee that every sensitive copy is avoided; clipboard history is not secure password storage. Disabling capture does not mean previously saved entries or backups have been erased.

The offline edition has no AI API connection, API-key setup, cloud dictation, voice conversation or wake-word listener. It does not request microphone input through these features or automatically upload your workspace to an Orbitavelle service. Explicitly opening configured links/resources uses the selected external application. Microsoft Store, Windows and WebView2 can perform their own platform operations under their own settings.

The ordinary database and exports are not application-level encrypted. Protect your Windows account/device and treat backups as sensitive. The in-app database backup is saved within this installation's application storage; make a separate copy in a location you control before relying on it for uninstall/recovery. A backup left only inside package storage is not an independent uninstall backup.

Local warning/error diagnostic files can be written and rotated. Error details can include local paths or application names. Review any diagnostic file before sharing it; the app does not attach it to support messages automatically. Do not send API keys, passwords, personal workspace contents or other sensitive information to support.

You control local clipboard history, folder watches, login startup and saved work. Uninstall can remove application storage and any backups kept inside it. Keep an independent backup outside that storage before uninstalling. Do not assume uninstall removes external backups or credentials left by a different/personal AI version. This offline edition does not read, copy or erase those personal AI credentials.

Support is user-initiated through the public support page. No notes, transcripts, recordings, keys or diagnostics are attached automatically. Send only the information needed to describe a problem and omit sensitive data.

If you email support, the publisher and email provider receive your email address, message and any attachments you choose to send. They are used to investigate and respond to the request. The support mailbox uses Microsoft Outlook, covered by Microsoft's privacy statement: https://www.microsoft.com/en-us/privacy/privacystatement . You can ask about or request deletion of support correspondence through the same support address. No fixed automatic deletion period is promised. Deleting local Orbitavelle data does not delete emails already sent.

The support website is a static GitHub Pages site. Its page code contains no advertising, analytics scripts, tracking cookies, login, contact-form backend or third-party font/image requests. GitHub may process technical request information, such as IP address and browser details, under its privacy statement: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement . Hosting operations are separate from Orbitavelle's local workspace storage. External links open a different site with its own practices; an email link opens your email app and does not send a message automatically.
